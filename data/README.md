# 配套科学数据

这里保存当前程序所用的完整本地数据文件。`manifest.json` 记录每个文件的来源、字节数和 SHA-256，迁移时已将 JPL 符号链接替换为真实文件。五份数据合计 49,365,142 字节，随本地 Git 仓库和源码包保存。

| 文件 | 用途与适用范围 |
| --- | --- |
| `eop/EOP-All_250516.txt` | 地球定向参数，文件版本 1.1，更新于 2025-05-15；包含 1962-01-01 至 2025-11-12 的记录，后段为预测值 |
| `ephemeris/JPLEPH_C.430` | JPL DE430/LE430。本地文件的二进制时间范围为 JED 2433264.5 至 2542864.5，即 1949-12-14 至 2250-01-10，分段长度 32 日 |
| `ephemeris/JPLEPH_C.440` | JPL DE440，沿用 LHH 地月观测算例的二进制实体文件；JED 2433264.5 至 2506352.5（1949-12-14 至 2150-01-22），分段长度 32 日；`tests/generate_cislunar_observations/input/` 保存同内容的实体文件 |
| `gravity/grail.txt` | NASA GSFC GRGM660PRIM 的 80 阶截取；GM、参考半径与系数配套，表头采用 SI 单位 |
| `atmosphere/atmosphere.txt` | 当前大气阻力模型使用的密度表；原文件来源标注 Ap=10、F10.7=150 |

JPL 文本标题保留了原始更长的时间区间，使用时以二进制头中的实际区间为准。地球重力场常数及现有系数由公共实现提供。

这些文件沿用作者已有科研资料，未更新内容。原资料中未附单独的数据再分发许可文本；来源和当前文件内容由清单记录。第三方软件的原始许可证另保存在 `third_party/`。

更新数据时同时更新清单，并核对算例时段和模型参数。EOP 文件中的观测段、预测段应按原标记使用。

## 月球重力场来源

`gravity/grail.txt` 对应 [NASA PDS 的 GRGM660PRIM](https://pds-geosciences.wustl.edu/grail/grail-l-lgrs-5-rdr-v1/grail_1001/shadr/gggrx_0660pm_sha.lbl)。已逐行核对本地保留的 3320 条系数记录，均与官方文件的 1 至 80 阶一致。文件头半径为 1738000 m，GM 为 4.90279980693169×10¹² m³/s²；GM 标准差同步换算到 SI，最大阶次注明为 80。官方文件和本地文件的 SHA-256、下载地址及转换步骤见 `manifest.json`。

该模型发布时使用 DE421 的月球主轴固连系。ASTER 当前用所加载 JPL 历表的天平动旋转到月固系；更换历表时须同时核对月固轴系。月球质点项采用所选 DE440 GM，二阶及以上球谐项采用本文件配套 GM、参考半径和系数。
